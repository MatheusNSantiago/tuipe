# tuipe

Um treinador de digitação offline e nativo de terminal que segue a semântica
de entrada do Monkeytype e aprende silenciosamente com dificuldades recorrentes.

A implementação ainda está em andamento. A referência comportamental congelada
é o commit `781dcd9fe66fb4d8fb3f5e408d1b057a2054b9d5` do Monkeytype; consulte
`NOTICE` e `PLAN.md`.
